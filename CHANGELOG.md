# Changelog

## 1.0.1 - 2026-08-28

### Changed

- Improved diagnostic log filenames to include the Vintage Story version and local language, or SERVER on dedicated servers.

## 1.0.0 - 2026-08-17

Initial public release of Targeted Prospecting.

### Added

- Targeted ore prospecting using a supported sample held in the off-hand.
- Scan area of 3 × 3 chunks.
- Waypoint count based on prospecting pick material.
- Steel bonus waypoint for supported gemstones.
- One targeted prospecting use per in-game day.
- Durability and saturation costs for targeted prospecting.
- Prospecting pick disassembly with partial metal recovery based on remaining durability.
- Czech and English localization.
- In-game handbook documentation.
- Optional diagnostic logger for troubleshooting and bug reports.
